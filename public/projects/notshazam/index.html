NotShazam

Music Fingerprinting & Identification

A music identification system that transforms audio into compact fingerprints, indexes them, and matches a query clip against a song library.

Project by Uday Gandhi · Research prototype

Source code ↗
350+ songs in library
11M+ indexed hashes
<200 ms reported match latency

01 · OVERVIEW

What the project does

NotShazam generates spectrogram-derived audio fingerprints, stores indexed hashes in MongoDB, and compares query clips against a song library. The project records a library of more than 350 songs and over 11 million indexed hashes, with matching latency reported below 200 milliseconds.

02 · IMPLEMENTATION

Features and engineering work

  • Generates and indexes spectrogram-derived audio hashes for a 350+ song library.
  • Uses fingerprint matching to identify audio, including clips sourced from YouTube streams.
  • Designed to retain matching robustness when recordings contain noise or distortion.
  • MongoDB stores the indexed fingerprint data for lookup.
