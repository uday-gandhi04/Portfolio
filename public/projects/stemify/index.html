Stemify

AI Audio Source Separation

An AI audio-separation application that splits a mixed track into vocal and instrumental stems using a phase-aware U-Net-family model.

Project by Uday Gandhi · Model + web interface

U-Net source-separation model

01 · OVERVIEW

What the project does

The project connects a custom deep-learning pipeline to a usable web workflow: upload audio, choose the separation output, run inference, and download the resulting stems.

02 · IMPLEMENTATION

Features and engineering work

  • Targets vocals, drums, bass, and other instrumental components from mixed audio.
  • Uses a phase-aware U-Net-based architecture and a composite loss intended to reduce separation artefacts.
  • Flask web interface accepts WAV/MP3 uploads and provides downloadable separated stems.
  • The resume also describes STFT-based tempo analysis and sheet-music transcription with PDF/XML export.

03 · HOW IT WORKS

From a mixed track to individual stems

Stemify processes an uploaded audio track through a phase-aware deep learning pipeline. Its DeepMultiSourceUNet model estimates individual sources from the mixed recording, producing separated audio stems.

  1. Audio input: The user uploads a WAV or MP3 recording through the Flask web interface.
  2. Audio preparation: The input is prepared for the model's audio-separation workflow.
  3. Deep learning inference: The phase-aware DeepMultiSourceUNet model processes the mixed audio and estimates its individual sources.
  4. Multi-source separation: The model produces separate stems for vocals, drums, bass and other instruments.
  5. Output delivery: The Flask application makes the separated audio outputs available for download.

Training approach

The model is trained using the MUSDB18 dataset. Its composite objective combines mean squared error, phase consistency, source independence and magnitude-sum terms to guide the separation process.
